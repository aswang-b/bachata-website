# Dance highlight photos

Drop your own story/highlight images here (JPG, PNG, or WebP; 9:16 aspect
ratio, e.g. 1080x1920, works best). They show up automatically on the
homepage's "Follow the Journey" viewer, in filename order — no code changes
needed.

Name them so the order is predictable, e.g.:

```
01-intro.jpg
02-social-night.jpg
03-competition.jpg
```

If this folder is empty, the homepage shows a placeholder message instead.
